# Explanation

Two things are happening:

1. **`useAuth must be used within AuthProvider`** — your running entry (`client/src/main.tsx`) isn’t wrapping the app with `AuthProvider` (and React Query). So `Navigation` calls `useAuth()` before any provider exists.
2. **“Skip to content” is visible** — that accessibility link is fine, but it needs CSS to be visually hidden until focused.

Below are **surgical fixes only**: wrap the app with the proper providers, hide the skip-link until focus, and ensure the Home hero is present with smooth transitions.

---

# Code

### 1) Wrap the whole app with providers (fixes the Auth error)

Replace the contents of **`client/src/main.tsx`** with this:

```tsx
import { StrictMode, Suspense } from "react";
import { createRoot } from "react-dom/client";
import { createBrowserRouter, RouterProvider } from "react-router-dom";
import "./index.css";

// Routes / pages (match your actual filenames/casing)
import App from "./routes/App";
import Home from "./pages/home";
import Solutions from "./pages/services";
import Platform from "./pages/Platform";
import Industries from "./pages/Industries";
import Pricing from "./pages/pricing";
import RoiCenter from "./pages/RoiCenter";
import Resources from "./pages/Resources";
import About from "./pages/about";
import Contact from "./pages/contact";
import Login from "./pages/login";
import CustomerDashboard from "./pages/customer-dashboard";

// Optional detail route (remove if you don't have the file)
import ResourceDetail from "./pages/ResourceDetail";

// Providers
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { AuthProvider } from "./contexts/AuthContext";
import { CartProvider } from "./contexts/CartContext";

// Guard
import PrivateRoute from "./ui/PrivateRoute";

const router = createBrowserRouter([
  {
    path: "/",
    element: <App />,
    children: [
      { index: true, element: <Home /> },
      { path: "solutions", element: <Solutions /> },
      { path: "platform", element: <Platform /> },
      { path: "industries", element: <Industries /> },
      { path: "pricing", element: <Pricing /> },
      { path: "roi", element: <RoiCenter /> },
      { path: "resources", element: <Resources /> },
      { path: "resources/:slug", element: <ResourceDetail /> },
      { path: "about", element: <About /> },
      { path: "contact", element: <Contact /> },
      { path: "login", element: <Login /> },
      {
        path: "customer-dashboard",
        element: (
          <PrivateRoute>
            <CustomerDashboard />
          </PrivateRoute>
        ),
      },
      { path: "*", element: <div className="p-8 text-center">404 — Not found</div> },
    ],
  },
]);

const qc = new QueryClient();

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <QueryClientProvider client={qc}>
      <AuthProvider>
        <CartProvider>
          <Suspense fallback={<div className="p-6">Loading…</div>}>
            <RouterProvider router={router} />
          </Suspense>
        </CartProvider>
      </AuthProvider>
    </QueryClientProvider>
  </StrictMode>
);
```

> If your project is wired to load `/src/main.tsx` in `index.html`, keep the tiny trampoline file at `src/main.tsx` with:
>
> ```ts
> import "../client/src/main.tsx";
> ```

### 2) Make the “Skip to content” link only appear on focus

Add these styles to the **top** of **`client/src/index.css`** (or your global CSS):

```css
/* Visually hide the skip link until keyboard focus */
.skip-link{
  position:absolute;
  left:-9999px;
  top:auto;
  width:1px;
  height:1px;
  overflow:hidden;
}
.skip-link:focus{
  left:1rem;
  top:1rem;
  width:auto;
  height:auto;
  padding:.5rem .75rem;
  background:#ffffff;
  color:#0f172a;               /* slate-900 */
  border:1px solid #cbd5e1;    /* slate-300 */
  border-radius:.5rem;
  box-shadow:0 4px 12px rgba(0,0,0,.12);
  z-index:10000;
}
```

Ensure your layout keeps the anchor target — in **`client/src/routes/App.tsx`** you should already have:

```tsx
<main id="main" className="flex-1"><Outlet /></main>
```

# Warnings

* Paths and casing matter (`Platform.tsx` vs `platform.tsx`).
* If you still see the Auth error, it means something is importing a **different** `AuthContext` than the provider. Make sure **all** imports use `../contexts/AuthContext` from **the same tree** (`client/src/**`), and remove any duplicate context files elsewhere.

- **2FA TOTP** for both admins and customers:
  - Enroll: generate secret (otpauth URL + QR), verify code to enable.
  - Login: after password validates, if 2FA enabled return `requires2FA=true`, accept `/api/auth/2fa/verify`.
- RBAC middleware:

  - `requirePermissions(...keys)` checks via role → role_permissions.
  - SuperAdmin bypasses org scoping.
- Security headers, CORS (allow current origin), CSRF (double-submit cookie for state-changing calls), input validation with Zod on every route.
- Encrypt all third-party tokens in `api_credentials` with `ENCRYPTION_KEY`.

Alright — the shell is failing because a few of the commands we told it to run either aren’t available in your Replit image (e.g. `wget`, `rsync`) or are being blocked/expanded weirdly. Here’s exactly how I’d hard-fix the environment and then re-run the mirroring steps without breakage.

# Explanation

* Replit uses **Nix** to provide system tools. If a tool (like `wget`, `rsync`, `curl`, `ripgrep`) isn’t in `replit.nix`, your shell calls will fail or behave inconsistently.
* Some flags need **exact** quoting; otherwise the shell expands globs (`*.css`) before `find`/`wget` sees them.
* Many sites block bots; we’ll set a **browser User-Agent** and a more compatible `wget` argument set. If `wget` still gets blocked, we’ll fall back to a **Node CLI scraper** so you can proceed.

# Code

### 1) `replit.nix` (add the tools we rely on)

Replace or merge to include these deps:

```nix
{ pkgs }: {
  deps = [
    pkgs.nodejs_20
    pkgs.git
    pkgs.wget
    pkgs.curl
    pkgs.rsync
    pkgs.ripgrep
    pkgs.findutils
    pkgs.coreutils
  ];
}
```

> After saving `replit.nix`, click **Rebuild** (Replit will prompt) so the tools are available in the shell.

### 2) Safe, copy-paste mirroring script (with guard rails)

Run this whole block **in the Shell** after the rebuild completes (one copy-paste):

```bash
set -euo pipefail

# Clean start
pkill -f "node|vite" || true

# Fresh import dirs
mkdir -p import vendor-tmp client/public/site client/src/styles
rm -rf import/* vendor-tmp/*

# Use wget with browser UA and friendly flags
UA='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36'

wget \
  --recursive --level=2 \
  --page-requisites --adjust-extension --convert-links \
  --no-parent --domains=victorysync.com \
  --user-agent="$UA" \
  --timeout=20 --tries=2 --wait=0.3 --random-wait \
  --directory-prefix=import \
  https://victorysync.com/

# If wget failed to fetch anything (blocked), fall back to website-scraper CLI
if [ ! -d import/victorysync.com ] || ! ls import/victorysync.com | grep -q . ; then
  npx --yes website-scraper@5.4.1 \
    --url https://victorysync.com \
    --directory import/victorysync.com \
    --max-depth 2 \
    --sources '{ "images": { "selector": "img", "attr": "src" }, "styles": { "selector": "link[rel=stylesheet]", "attr": "href" }, "scripts": { "selector": "script", "attr": "src" } }' || true
fi

# Collect assets (images/fonts/icons) to public/site
rsync -a --prune-empty-dirs \
  --include "*/" \
  --include "*.png" --include "*.jpg" --include "*.jpeg" --include "*.webp" \
  --include "*.svg" --include "*.ico" \
  --include "*.woff" --include "*.woff2" \
  --exclude "*" \
  import/victorysync.com/ client/public/site/

# Gather mirrored CSS/JS into a temp bucket for review
rsync -a --prune-empty-dirs \
  --include "*/" --include "*.css" --include "*.js" --exclude "*" \
  import/victorysync.com/ vendor-tmp/

# Concatenate CSS (quoted glob so the shell doesn’t expand incorrectly)
if find vendor-tmp -type f -name '*.css' | grep -q . ; then
  find vendor-tmp -type f -name '*.css' -print0 | sort -z | xargs -0 cat > client/src/styles/site.css
else
  # ensure the file exists (empty) so imports don’t fail
  : > client/src/styles/site.css
fi
```

# Instructions

1. **Update `replit.nix`** as shown and click **Rebuild** when Replit prompts.
2. Paste **the whole mirroring script** into the shell and run it.

   * If `wget` is blocked by the host, the script auto-tries `website-scraper` via `npx`.
3. Ensure `client/src/main.tsx` imports `./styles/site.css`.
4. Build and serve: `npm run build && npm run serve`.
   Preview should now load with your mirrored assets available under `/site/...`.

# Warnings / Preventing a repeat

* Missing tools cause most “command not found” errors in Replit. Always add them to **`replit.nix`** and rebuild once.
* Quote globs in `find`/`grep` commands (`'*.css'`) so the shell doesn’t expand them before the command runs.
* Sites with Cloudflare may still block bulk mirroring. The **UA header**, gentle `--wait`, and the **fallback `website-scraper`** handle most cases.
* Don’t hot-link assets to the live domain; keep them in `client/public/site` so local builds never 404.

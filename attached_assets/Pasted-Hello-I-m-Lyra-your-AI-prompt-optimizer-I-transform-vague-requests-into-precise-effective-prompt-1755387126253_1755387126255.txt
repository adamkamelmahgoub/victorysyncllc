Replace your current dev catch-all with this block (keep the rest of the file as-is: API routes, health, listen, etc.):

```ts
// server/index.ts (inside boot(), dev branch)
import fs from "node:fs";
import path from "node:path";

if (!isProd) {
  const { createServer } = await import("vite");
  const vite = await createServer({
    root: clientRoot,
    server: { middlewareMode: true, hmr: { clientPort: 443 }, watch: { usePolling: true } },
    appType: "custom"
  });
  app.use(vite.middlewares);

  // Disable CSP ONLY in dev so Vite can inject inline preamble safely
  // (If you're using helmet, wrap helmet() with this guard)
  // e.g. app.use(helmet({ contentSecurityPolicy: false }));

  app.get("*", async (req, res, next) => {
    if (req.path.startsWith("/api")) return next();
    try {
      const indexHtmlPath = path.resolve(clientRoot, "index.html");
      let html = fs.readFileSync(indexHtmlPath, "utf-8");

      // Let Vite inject @vite/client and React refresh preamble
      html = await vite.transformIndexHtml(req.originalUrl, html);

      // EXTRA GUARANTEE: if the preamble wasn't injected (edge cases), inject it manually
      if (!html.includes("/@vite/client") || !html.includes("__vite_plugin_react_preamble_installed__")) {
        const preamble = `
          <script type="module" src="/@vite/client"></script>
          <script type="module">
            import RefreshRuntime from "/@react-refresh";
            RefreshRuntime.injectIntoGlobalHook(window);
            window.$RefreshReg$ = () => {};
            window.$RefreshSig$ = () => (type) => type;
            window.__vite_plugin_react_preamble_installed__ = true;
          </script>`;
        html = html.replace("</head>", `${preamble}\n</head>`);
      }

      res.status(200).setHeader("Content-Type", "text/html").end(html);
    } catch (err) {
      vite.ssrFixStacktrace(err as Error);
      next(err);
    }
  });
} else {
  // keep your existing prod static + SPA fallback
}
```

> Why: Vite’s React fast-refresh relies on a **preamble script** injected via the HTML transform pipeline. If anything prevents that (custom HTML string, strict CSP), React plugin warns and you get a blank page. The code above both **uses `transformIndexHtml`** and **manually injects** the preamble if needed.

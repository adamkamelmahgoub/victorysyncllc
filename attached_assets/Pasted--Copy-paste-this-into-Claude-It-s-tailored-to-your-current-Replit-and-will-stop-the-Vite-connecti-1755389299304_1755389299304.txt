# Explanation

Replit’s HTTPS proxy intermittently kills Vite’s HMR websocket, which causes the Vite client to force reloads → flicker/blank screen. The simplest, bullet-proof approach in Replit is to **run the client in “prod-style” during dev**: build once and serve the built `/client/dist` from Express with SPA fallback (no Vite dev server, no HMR). Locally we can still use normal HMR; but **in Replit we disable it**.

  }

> Notes

### 4) `server/index.ts` — detect Replit/dev-static mode and serve `/client/dist` with SPA fallback; keep everything else (auth, APIs, dashboards) unchanged

Edit this file as follows (don’t remove existing routes/middleware; just apply the structure below).

```ts
import "dotenv/config";
import express from "express";
import path from "path";
import { fileURLToPath } from "url";

// ______________________________________
// Replit / static-dev detection
const IN_REPLIT = !!process.env.REPL_ID || !!process.env.REPLIT_DB_URL;
const DEV_STATIC = IN_REPLIT || process.env.DEV_STATIC === "1";
const NODE_ENV = process.env.NODE_ENV ?? "development";
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const PORT = Number(process.env.PORT || 5000);
const app = express();

app.set("trust proxy", 1);
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// ----- Your existing API routes go here (auth, billing, admin, customer, etc.) -----
// e.g. app.use("/api", apiRouter);

// ______________________________________
// SPA: serve built client in Replit (DEV_STATIC) and in production
const distDir = path.resolve(__dirname, "../client/dist");
const indexHtml = path.resolve(distDir, "index.html");

if (NODE_ENV === "production" || DEV_STATIC) {
  app.use(express.static(distDir, { maxAge: NODE_ENV === "production" ? "1h" : 0 }));

  // SPA fallback for non-API routes
  app.get("*", (req, res, next) => {
    if (req.path.startsWith("/api")) return next();
    res.sendFile(indexHtml);
  });
} else {
  // Local (non-Replit) dev can still use Vite middleware if you want.
  // For Replit we don't use this branch.
  const { createServer: createViteServer } = await import("vite");
  const vite = await createViteServer({
    root: path.resolve(__dirname, "../client"),
    server: { middlewareMode: true },
    appType: "custom"
  });
  app.use(vite.middlewares);
  app.get("*", async (req, res, next) => {
    if (req.path.startsWith("/api")) return next();
    try {
      const html = await vite.transformIndexHtml(req.originalUrl, "<!DOCTYPE html><html><head></head><body><div id='root'></div><script type='module' src='/src/main.tsx'></script></body></html>");
      res.status(200).set({ "Content-Type": "text/html" }).end(html);
    } catch (e) {
      vite.ssrFixStacktrace(e as Error);
      next(e);
    }
  });
}

// ______________________________________
// Keep-alive so proxy doesn’t kill sockets prematurely
const server = app.listen(PORT, "0.0.0.0", () => {
  console.log(`🎉 VictorySync on http://0.0.0.0:${PORT}  env=${NODE_ENV}  IN_REPLIT=${IN_REPLIT}  DEV_STATIC=${DEV_STATIC}`);
});
server.keepAliveTimeout = 70_000;
server.headersTimeout = 75_000;
server.on("connection", s => s.setKeepAlive(true, 60_000));
```

> Important: Do **not** remove your existing API routes, auth, dashboards, or middleware; just keep them above the SPA section as shown. The only change is **how the client is served** in Replit.

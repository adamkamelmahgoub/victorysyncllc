# Explanation

You’ll get a **production-ready, no-surprises implementation** that maps each plan (Starter/Growth/Scale) to precise **entitlements**, locks features behind those entitlements, wires billing with **Stripe**, and toggles **live chat, appointment booking, AI automations, priority routing, reports, and real-time analytics** only when the plan allows it.

This is designed for **Replit** deployment as a single service: the Node/Express API serves your built React app and handles webhooks, jobs, and sockets. You’ll paste the files below into your repo. It’s opinionated, minimal, and stable.

```ts
import { pgTable, varchar, integer, boolean, timestamp, jsonb, primaryKey } from "drizzle-orm/pg-core";

export const organizations = pgTable("organizations", {
  id: varchar("id", { length: 36 }).primaryKey(),
  name: varchar("name", { length: 120 }).notNull(),
  timezone: varchar("timezone", { length: 64 }).default("America/New_York").notNull(),
  stripeCustomerId: varchar("stripe_customer_id", { length: 80 }),
  planId: varchar("plan_id", { length: 16 }).notNull(), // 'starter' | 'growth' | 'scale'
  createdAt: timestamp("created_at").defaultNow()
});

export const features = pgTable("features", {
  id: varchar("id", { length: 64 }).primaryKey(),      // e.g. 'live_chat'
  label: varchar("label", { length: 120 }).notNull(),
  description: varchar("description", { length: 400 })
});

export const plans = pgTable("plans", {
  id: varchar("id", { length: 16 }).primaryKey(),      // 'starter'|'growth'|'scale'
  stripePriceId: varchar("stripe_price_id", { length: 80 }), // null → "Get a quote"
  agentSeats: integer("agent_seats").default(1),
  hoursPreset: varchar("hours_preset", { length: 16 }).notNull() // 'business'|'extended'|'24x7'
});

export const planFeatures = pgTable("plan_features", {
  planId: varchar("plan_id", { length: 16 }).notNull(),
  featureId: varchar("feature_id", { length: 64 }).notNull(),
}, (t) => ({ pk: primaryKey({ columns: [t.planId, t.featureId] }) }));

export const entitlements = pgTable("entitlements", {
  orgId: varchar("org_id", { length: 36 }).notNull(),
  featureId: varchar("feature_id", { length: 64 }).notNull(),
  value: jsonb("value"),
  enabled: boolean("enabled").default(true)
}, (t) => ({ pk: primaryKey({ columns: [t.orgId, t.featureId] }) }));
```

```ts
const F = {

  success_manager: "Dedicated Success Manager",
  custom_integrations: "Custom Integrations",
  priority_support: "Priority Support",
  realtime_analytics: "Real-time Analytics"
};

const STARTER = ["dedicated_agent","business_hours","crm_basic","email_support","reports_monthly"] as const;
const GROWTH  = [...STARTER,"second_agent","extended_hours","appointments","crm_advanced","live_chat","reports_weekly"] as const;
const SCALE   = [...GROWTH,"blended_24x7","ai_suite","success_manager","custom_integrations","priority_support","realtime_analytics"] as const;

async function run() {
  // features
  for (const [id,label] of Object.entries(F)) {
    await db.insert(features).values({ id, label }).onConflictDoNothing();
  }
  // plans
  await db.insert(plans).values(
    { id:"starter", stripePriceId: process.env.STRIPE_PRICE_STARTER ?? null, agentSeats:1, hoursPreset:"business" },
  ).onConflictDoNothing();
  await db.insert(plans).values(
    { id:"growth", stripePriceId: process.env.STRIPE_PRICE_GROWTH ?? null, agentSeats:2, hoursPreset:"extended" },
  ).onConflictDoNothing();
  await db.insert(plans).values(
    { id:"scale", stripePriceId: null, agentSeats:2, hoursPreset:"24x7" },
  ).onConflictDoNothing();

  // helpers
  async function link(planId: "starter"|"growth"|"scale", list: readonly string[]) {
    for (const featureId of list) {
      await db.insert(planFeatures).values({ planId, featureId }).onConflictDoNothing();
    }
  }
  await link("starter", STARTER as unknown as string[]);
  await link("growth", GROWTH as unknown as string[]);
  await link("scale", SCALE as unknown as string[]);
  console.log("Seed complete.");
}
run().then(()=>process.exit(0)).catch(e => { console.error(e); process.exit(1); });
```

**server/middleware/entitlements.ts**

```ts
import { db } from "../db/client";
import { entitlements } from "../db/schema";
import { and, eq } from "drizzle-orm";

export async function requireFeature(orgId: string, featureId: string) {
  const rows = await db.select().from(entitlements)
    .where(and(eq(entitlements.orgId, orgId), eq(entitlements.featureId, featureId))).limit(1);
  if (!rows.length || rows[0].enabled !== true) {
    const e = new Error(`Feature ${featureId} not enabled for this plan`);
    (e as any).status = 403;
    throw e;
  }
  return rows[0].value ?? {};
}
```

**server/billing/stripe.ts**

```ts
import Stripe from "stripe";
import { db } from "../db/client";
import { organizations, planFeatures, entitlements, plans } from "../db/schema";
import { eq } from "drizzle-orm";

export const stripe = new Stripe(process.env.STRIPE_SECRET!, { apiVersion: "2024-06-20" });

export async function createCheckout(orgId: string, planId: "starter"|"growth"|"scale") {
  const plan = await db.query.plans.findFirst({ where: eq(plans.id, planId) });
  if (!plan) throw new Error("Plan not found");
  if (!plan.stripePriceId) throw new Error("Quote required for Scale");

  const org = await db.query.organizations.findFirst({ where: eq(organizations.id, orgId) });
  const session = await stripe.checkout.sessions.create({
    mode: "subscription",
    customer: org?.stripeCustomerId || undefined,
    line_items: [{ price: plan.stripePriceId, quantity: 1 }],
    success_url: `${process.env.APP_URL}/billing/success`,
    cancel_url: `${process.env.APP_URL}/pricing`
  });
  return session.url!;
}

export async function applyPlanToOrg(orgId: string, planId: "starter"|"growth"|"scale") {
  // Update org
  await db.update(organizations).set({ planId }).where(eq(organizations.id, orgId));

  // Replace entitlements to exactly match plan
  const links = await db.select().from(planFeatures).where(eq(planFeatures.planId, planId));
  await db.execute(/* sql */`delete from entitlements where org_id = $1`, [orgId]);
  for (const l of links) {
    await db.insert(entitlements).values({ orgId, featureId: l.featureId, enabled: true }).onConflictDoNothing();
  }
}
```

**server/routes/index.ts**

```ts
import { Router } from "express";
import { createCheckout, applyPlanToOrg, stripe } from "../billing/stripe";
import { requireFeature } from "../middleware/entitlements";
import { db } from "../db/client";
import { organizations, entitlements } from "../db/schema";
import { eq } from "drizzle-orm";

export const router = Router();

// Billing → create checkout
router.post("/billing/checkout/:planId", async (req, res, next) => {
  try {
    const planId = req.params.planId as "starter"|"growth"|"scale";
    const orgId = (req as any).auth?.orgId;
    if (!orgId) throw new Error("Unauthorized");
    const url = await createCheckout(orgId, planId);
    res.json({ url });
  } catch (e) { next(e); }
});

// Webhook (Stripe)
router.post("/webhooks/stripe", async (req, res, next) => {
  try {
    const sig = req.headers["stripe-signature"] as string;
    const evt = stripe.webhooks.constructEvent(req.body, sig, process.env.STRIPE_WEBHOOK_SECRET!);

    if (evt.type === "checkout.session.completed") {
      const s = evt.data.object as any;
      // Resolve org from your metadata or customer mapping
      const org = await db.query.organizations.findFirst({ where: eq(organizations.stripeCustomerId, s.customer as string) });
      if (org) {
        // Map price → planId (store this mapping in DB or env)
        const price = (s.line_items?.data?.[0]?.price?.id) || s.display_items?.[0]?.price?.id;
        let planId: "starter"|"growth"|"scale" | null = null;
        if (price === process.env.STRIPE_PRICE_STARTER) planId = "starter";
        if (price === process.env.STRIPE_PRICE_GROWTH) planId = "growth";
        if (planId) await applyPlanToOrg(org.id, planId);
      }
    }
    res.json({ received: true });
  } catch (e) { next(e); }
});

// Feature-gated endpoints (examples)
router.post("/appointments/book", async (req, res, next) => {
  try {
    const orgId = (req as any).auth?.orgId!;
    await requireFeature(orgId, "appointments");
    // Call Cal.com or your scheduling API here
    res.json({ ok: true });
  } catch (e) { next(e); }
});

router.get("/me/entitlements", async (req, res, next) => {
  try {
    const orgId = (req as any).auth?.orgId!;
    const list = await db.select().from(entitlements).where(eq(entitlements.orgId, orgId));
    res.json({ features: list.map(r => r.featureId) });
  } catch (e) { next(e); }
});
```

# Instructions

1. **Environment variables (Replit → Secrets)**

   * `DATABASE_URL` = your Postgres URL
   * `APP_URL` = your app base (e.g., [https://victorysync.repl.co](https://victorysync.repl.co))
   * `STRIPE_SECRET` = Stripe secret key
   * `STRIPE_WEBHOOK_SECRET` = from the webhook endpoint
   * `STRIPE_PRICE_STARTER` = price\_… for \$1,200 plan
   * `STRIPE_PRICE_GROWTH` = price\_… for \$2,500 plan
   * `PGSSL` = `false` if local/self-hosted Postgres without SSL
   * (Frontend) add `VITE_CRISP_ID` in Replit “Secrets” too

2. **Install & build**

   * Open Replit shell:

     ```
     npm i
     npm run seed:plans
     npm run build
     npm run start
     ```
   * Your app serves the built client from `server/public`.

3. **Stripe webhook**

   * Add an endpoint: `POST {APP_URL}/api/webhooks/stripe`
   * Events needed: `checkout.session.completed`, `customer.subscription.updated`
   * In the code, `applyPlanToOrg` updates the org and resets entitlements.

4. **Connect your live systems**

   * **Live chat (Growth+):** put `VITE_CRISP_ID` in secrets; the component autoloads when `live_chat` entitlement exists.
   * **Appointments (Growth+):** update the URL in `Booker.tsx` to your Cal.com team.
   * **AI Suite (Scale):** connect your n8n HTTP endpoints behind the `requireFeature(orgId,"ai_suite")` guard in dedicated routes.
   * **Priority routing (Scale):** where you dequeue tasks/calls, set queue weights based on plan (`priority_support`).
   * **Reports:** wire your Puppeteer report generator in `jobs/reports.ts`.

5. **Replace the temporary auth**

   * Swap `fakeAuth` with your JWT middleware that resolves `(req as any).auth = { orgId }` after validating the token.
   * The **only** requirement is to pass a valid `orgId` into the request context.

6. **Zero-downtime deploy on Replit**

   * Keep `start` script; Replit restarts your process if it crashes.
   * Use Postgres with SSL; set `PGSSL=false` only if you know you’re on a trusted network.

---

# Warnings

* **Do not enable Scale (24/7) until on-call/escalations are verified** end-to-end.
* **Secure your webhooks** (already HMAC-validated for Stripe). Do the same for email/chat/CRM inbound webhooks.
* **Handle PII carefully**: store only what’s needed; encrypt per-org secrets at rest.
* **Backups & rollbacks**: enable automated DB backups; keep Drizzle migrations in VCS.

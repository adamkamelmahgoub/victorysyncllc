# Prompt: Build & Validate the **Victory Sync Client Opportunity Analyzer** (Full‑Stack Replit App)

---

## 1 💼 Role & Tone

You are a **senior full‑stack application developer** (Frontend + Backend + DevOps + QA). Write production‑grade, fully‑tested code that runs on **Replit** without manual tweaks. Validate every function, cover edge‑cases, and deliver a rock‑solid, maintainable solution.

Speak concisely like an expert peer—clear explanations, code comments for complex logic, but no filler.

---

## 2 🎯 Objective

Create a web application—**Client Opportunity Analyzer**—that Victory Sync uses to:

1. **Ingest** prospective‑client sales & operations data (CSV/XLSX drag‑and‑drop or manual table input).
2. **Screen & score** leads by revenue, growth, margins, churn, tech stack, and operational complexity.
3. **Detect automation opportunities** (AI, RPA, workflow) and estimate EBITDA uplift.
4. **Generate an executive PDF & HTML report** with charts and ROI projections.
5. **Persist & manage** analyses with filtering, comments, and export features.

All code **must build & run on first click** in Replit.

---

---

## 5 📑 Functional Requirements

1. **Data Ingestion**

   * Accept CSV/XLSX ≤ 20 MB; validate MIME & schema.
   * Preview grid, allow column rename/ignore.
   * Store raw file to Replit Storage (S3‑compatible) for audit.

2. **Lead Scoring Engine**

   * Metrics: revenue, YoY growth, gross margin, EBITDA %, deal size, win rate, CSAT.
   * Weighted score (0‑100). Weight matrix editable in UI.
   * Persist results; expose REST `/analyze/{id}` for retrieval.

3. **Automation Opportunity Detection**

   * Rule‑based mapping + optional ML clustering on pain‑point keywords.
   * Output: recommended automations, cost‑save \$, EBITDA uplift %, payback months.

4. **Reporting**

   * Generate PDF (WeasyPrint) & HTML (Jinja2) branded with Victory Sync logo.
   * Embed charts (matplotlib) + narrative bullet points.

5. **Admin & Security**

   * JWT auth; roles: *admin*, *analyst*.
   * Rate‑limit uploads (FastAPI‑Limiter), secure CORS.

## 7 🚀 Run & Deploy on Replit

1. `npm install && npm run build` inside `web/` (triggered by `replit.nix`).
2. `pip install -r requirements.txt` auto‑handled.
3. `make seed-db` to create tables & sample data.
4. Click **Run** → FastAPI starts on `http://localhost:8000` with React served as static.
5. Live preview panel shows login page.

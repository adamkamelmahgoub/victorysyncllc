Got it — the blank page plus the console error

> **Cannot read properties of null (reading 'useEffect')**

means your browser bundle is loading, but React is ending up **null** in at least one file (something is doing `React.useEffect(...)`). That typically happens when we switched to the modern JSX transform (`"jsx": "react-jsx"`) but still call hooks off a default `React` import.

Below is a focused, copy-pasteable set of fixes to get your **original frontend** rendering again (with Vite in dev and the built SPA in prod), and to remove the `useEffect` error for good.

---

## 1) One-time search & replace (fix the null React issue)

In the **client/src** folder:

* **Find** all occurrences of `React.useEffect(` and replace with `useEffect(`.
* If you see `React.useState(`, replace with `useState(`, etc.

Then, at the **top of those files**, make sure you have **named hook imports**:

```ts
import { useEffect, useState, useMemo, useRef, useCallback } from 'react';
```

> Do **not** rely on `React.useEffect`. With `"jsx": "react-jsx"`, React isn’t auto-bound to the name `React`.

If any file still uses `React` for other reasons (like `React.Fragment`), keep:

```ts
import * as React from 'react';
```

…but still **import hooks by name** as shown above.

## 3) Keep the server behavior you want (API + SPA)

You already have the server printing:

```
No built SPA found ... Serving API only. FRONTEND_URL=http://localhost:5173
```

That’s perfect for dev: the API runs on Replit’s port, and the frontend runs separately on Vite (`5173`).

For production on Replit (or when you want the **original site** to show at the root), you need a built SPA in `client/dist` and a static fallback:

### In `server/index.ts` (or your express entry), add this after your API routes:

```ts
import path from 'node:path';
import express from 'express';

const app = express();

// ... your API routes first ...

// Serve built SPA if it exists
const distDir = path.join(process.cwd(), 'client', 'dist');
app.use(express.static(distDir));
app.get('*', (_req, res, next) => {
  // if the index.html exists, serve it; otherwise, let the earlier code print the dev message
  res.sendFile(path.join(distDir, 'index.html'), err => {
    if (err) next(); // falls through to your “No built SPA…” message
  });
});
```

This way:

* **DEV**: if `client/dist/index.html` doesn’t exist, your message appears and you use Vite at `5173`.
* **PROD**: after you run a build, the server serves the **original frontend** from `client/dist` at `GET /`.

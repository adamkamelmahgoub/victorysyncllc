# Explanation

Your server boots, connects to Postgres, then crashes with:

```
ReferenceError: packages is not defined
 at initializeApp (server/index.ts:153:25)
```

That means `server/index.ts` is referencing a variable named `packages` (almost certainly your **Drizzle table**), but it isn’t imported. Fix by importing the table from your DB schema (or, if you don’t actually have a `packages` table, use the correct table name — e.g., `plans`).

# Warnings

* Don’t leave bare identifiers that shadow table names; prefer explicit aliases like `packages as packagesTable` to avoid collisions with variables/constants.
* If you seed multiple tables at boot, make each seeder **idempotent** (use `onConflictDoNothing()` or `where not exists`).

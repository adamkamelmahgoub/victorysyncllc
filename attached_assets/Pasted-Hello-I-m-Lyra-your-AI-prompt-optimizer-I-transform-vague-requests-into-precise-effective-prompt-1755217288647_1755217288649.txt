This error happens when `React` is **null** at runtime—usually due to:

* importing `React` and then calling `React.useState` while `React` got shadowed or resolved to the wrong module, or
* duplicate/incorrect React versions, or
* an alias misconfig causing multiple React builds.

## 3) Convert **all** `React.useX` calls to named hooks

**Do a project-wide refactor (client/src only):**

* Replace:

  * `import React from "react";` **and** usage like `React.useState`, `React.useEffect`, `React.useMemo`…
* With:

  * `import { useState, useEffect, useMemo, useRef, useContext, createContext } from "react";`
  * And call `useState(...)`, `useEffect(...)`, etc. (no `React.` prefix)

**Example – Fix context/components that still use `React.` namespace**

*Edit `client/src/context/cart.tsx` (overwrite to be safe):*

```tsx
import { createContext, useContext, useState, PropsWithChildren } from "react";

type CartItem = { id: string; qty: number };
type CartContextValue = {
  items: CartItem[];
  addItem: (id: string, qty?: number) => void;
  clear: () => void;
};

const CartContext = createContext<CartContextValue | undefined>(undefined);

export function CartProvider({ children }: PropsWithChildren) {
  const [items, setItems] = useState<CartItem[]>([]);

  const addItem = (id: string, qty = 1) =>
    setItems(prev => {
      const i = prev.findIndex(x => x.id === id);
      if (i > -1) { const copy = [...prev]; copy[i] = { ...copy[i], qty: copy[i].qty + qty }; return copy; }
      return [...prev, { id, qty }];
    });

  const clear = () => setItems([]);

  return <CartContext.Provider value={{ items, addItem, clear }}>{children}</CartContext.Provider>;
}

export function useCartContext() {
  const v = useContext(CartContext);
  if (!v) throw new Error("useCartContext must be used within a CartProvider");
  return v;
}
```

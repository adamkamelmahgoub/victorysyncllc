You’re seeing “useAuth must be used within AuthProvider” because parts of the app are rendering from **/client/src** while the provider wrap is coming from a different tree (or not wrapping at all). Fix by making **/client/src/main.tsx** the single entry and wrapping the entire router there.

Do exactly this—nothing else:

# Code

## 1) Point entry to the client tree

In **index.html** (root), make the script target **/client/src/main.tsx**:

```diff
- <script type="module" src="/src/main.tsx"></script>
+ <script type="module" src="/client/src/main.tsx"></script>
```

## 2) Replace `client/src/main.tsx` with a provider-wrapped root

This guarantees `Navigation` (which calls `useAuth`) is always under `AuthProvider`.

```tsx
// client/src/main.tsx
import { StrictMode, Suspense } from "react";
import { createRoot } from "react-dom/client";
import { createBrowserRouter, RouterProvider } from "react-router-dom";
import "./index.css";

// pages (match your filenames exactly)
import App from "./routes/App";
import Home from "./pages/home";
import Solutions from "./pages/services";
import Platform from "./pages/Platform";
import Industries from "./pages/Industries";
import Pricing from "./pages/pricing";
import RoiCenter from "./pages/RoiCenter";
import Resources from "./pages/Resources";
import About from "./pages/about";
import Contact from "./pages/contact";
import Login from "./pages/login";
import CustomerDashboard from "./pages/customer-dashboard";

// NEW: resource detail route (optional, keeps resource links in-app)
import ResourceDetail from "./pages/ResourceDetail";

// providers
import { CartProvider } from "./contexts/CartContext";
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { AuthProvider } from "./contexts/AuthContext";

// route guard
import PrivateRoute from "./ui/PrivateRoute";

const router = createBrowserRouter([
  {
    path: "/",
    element: <App />,
    children: [
      { index: true, element: <Home /> },
      { path: "solutions", element: <Solutions /> },
      { path: "platform", element: <Platform /> },
      { path: "industries", element: <Industries /> },
      { path: "pricing", element: <Pricing /> },
      { path: "roi", element: <RoiCenter /> },
      { path: "resources", element: <Resources /> },
      { path: "resources/:slug", element: <ResourceDetail /> }, // safe if present
      { path: "about", element: <About /> },
      { path: "contact", element: <Contact /> },
      { path: "login", element: <Login /> },
      {
        path: "customer-dashboard",
        element: (
          <PrivateRoute>
            <CustomerDashboard />
          </PrivateRoute>
        )
      },
      { path: "*", element: <div className="p-8 text-center">404 — Not found</div> }
    ]
  }
]);

const qc = new QueryClient();

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <QueryClientProvider client={qc}>
      <AuthProvider>
        <CartProvider>
          <Suspense fallback={<div className="p-6">Loading…</div>}>
            <RouterProvider router={router} />
          </Suspense>
        </CartProvider>
      </AuthProvider>
    </QueryClientProvider>
  </StrictMode>
);
```

## 3) Ensure your `Navigation` imports the same Auth context

Open **client/src/components/navigation.tsx** and confirm the import:

```ts
import { useAuth } from "../contexts/AuthContext";
```

(If your `navigation.tsx` lives in `components/ui/`, use `../../contexts/AuthContext`—the key is that it points to the **client/src** context, not a `/src` copy.)

# Why this fixes it

You had two source roots (`/src` and `/client/src`). The app was sometimes loading components from **/client/src** while the provider came from the other tree, so `useAuth()` saw no provider and threw. Forcing the entry to **/client/src/main.tsx** and wrapping the Router there guarantees the same instance of `AuthContext` across Navigation and the rest of the app.

# Quick sanity checks

* Only one `AuthContext.tsx` should exist under **client/src/contexts/**.
* The console should show routes resolving without the Auth error after you save the two files and re-run.

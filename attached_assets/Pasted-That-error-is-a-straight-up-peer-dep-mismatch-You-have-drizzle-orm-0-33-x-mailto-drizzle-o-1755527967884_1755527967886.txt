That error is a straight-up peer-dep mismatch:

* You have **[drizzle-orm@0.33.x](mailto:drizzle-orm@0.33.x)**
* You asked npm to install **drizzle-zod\@0.7.0**
* But `drizzle-zod@0.7.0` requires **drizzle-orm >= 0.36.0**

You can fix it in one of two clean ways. I recommend **Option A (upgrade drizzle-orm)**.

---

# Option A — Upgrade `drizzle-orm` to match `drizzle-zod@0.7`

### 1) Paste this “do-it” script in the Replit shell

```bash
# from the repo root
rm -rf node_modules package-lock.json
npm i drizzle-orm@^0.44.4 drizzle-zod@^0.7.0

# If you use these, keep them aligned too:
npm i -D drizzle-kit@^0.26.2
npm i pg@^8.11.5                # for Postgres driver (if you use pg)
npm i @types/pg@^8.10.2 -D      # types (if TS + pg)
```

> Why 0.44.x? It’s current and fully compatible with drizzle-zod\@0.7.

### 2) Make sure your Drizzle imports match modern `drizzle-orm`

Check your DB/bootstrap files. They should look like this (adjust driver as needed):

```ts
// server/db/client.ts
import { Pool } from 'pg'
import { drizzle } from 'drizzle-orm/node-postgres'
import * as schema from './schema' // your tables

const pool = new Pool({
  connectionString: process.env.DATABASE_URL!,
  ssl: process.env.DB_SSL === 'true' ? { rejectUnauthorized: false } : undefined,
})

export const db = drizzle(pool, { schema })
```

```ts
// server/db/schema.ts
import {
  pgTable, serial, varchar, text, integer, timestamp, boolean, jsonb
} from 'drizzle-orm/pg-core'
import { relations } from 'drizzle-orm'
import { z } from 'zod'
import { createInsertSchema, createSelectSchema } from 'drizzle-zod'

// Example table
export const users = pgTable('users', {
  id: serial('id').primaryKey(),
  email: varchar('email', { length: 255 }).notNull().unique(),
  passwordHash: text('password_hash').notNull(),
  role: varchar('role', { length: 32 }).notNull(),
  orgId: integer('org_id'),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull(),
})

export const insertUserSchema = createInsertSchema(users)
export const selectUserSchema = createSelectSchema(users)
export type User = typeof users.$inferSelect
export type NewUser = typeof users.$inferInsert
```

And when you query:

```ts
import { eq, and, desc } from 'drizzle-orm'
import { db } from '../db/client'
import { users } from '../db/schema'

const u = await db.query.users.findFirst({
  where: eq(users.email, email.toLowerCase()),
})
```

If you previously imported from deprecated paths, update them to:

* `drizzle-orm/pg-core`
* `drizzle-orm/node-postgres`
* `drizzle-orm` (for `eq`, `and`, etc.)

### 3) Reinstall and build

```bash
npm i
npm run build
```

If you also maintain a **client/** folder, run its install separately (it’s unrelated to this error but good hygiene):

```bash
npm --prefix client i
```

# Option B — Keep `drizzle-orm@0.33.x` and **downgrade** `drizzle-zod`

If you can’t upgrade `drizzle-orm` right now, pin `drizzle-zod` to a version that still supports it (e.g. `0.6.1`):

```bash
rm -rf node_modules package-lock.json
npm i drizzle-orm@0.33.x drizzle-zod@0.6.1
npm i
```

(If 0.6.1 still complains, try `0.5.x`; the constraint changed around 0.7.)

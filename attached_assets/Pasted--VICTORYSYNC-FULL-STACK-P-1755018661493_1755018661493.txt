FUNCTIONAL REQUIREMENTS
────────────────────────────────────────────────────────────────────
A. **Authentication & Security**
   1. JWT auth (HTTP-only cookies) + refresh token rotation.
   2. 2-Factor Authentication (email TOTP fallback SMS) for:
      • Super-Admin  • Internal Admins  • Customers (org owners + sub-users).
   3. Password policy (12-char, mixed) + bcrypt 12 rounds.
   4. Rate-limit all auth routes (express-rate-limit).
   5. RBAC middleware: roles = SUPER_ADMIN | ADMIN | ORG_OWNER | ORG_USER.

B. **Super-Admin Portal**
   • Dashboard metrics: Total Orgs | Paying Orgs | Active Agents | MRR | API usage.
   • **Global User Management**  
     – CRUD for *all* admins & customers.  
     – Bulk disable / force reset pwd / 2FA reset.  
   • **Org Management**  
     – View + edit org profile, subscription tier, MAX seats, feature toggles.  
     – Issue **single-use access codes** (UUIDv4) → email or copy to clipboard.  
   • Feature flag manager (boolean + % rollout).  
   • Audit log table (actor, action, entity, diff, IP, ts).  
   • Logs/metrics export CSV.

C. **Internal Admin Portal**
   • Super-Admin decides per-admin permissions (`user.read`, `org.write`, etc.).  
   • Same UI as super-admin but limited by RBAC.

D. **Customer Portal**
   Tabs: **Overview | KPI Tracker | Integrations | Billing | Settings**  
   1. Overview: live widgets (active agents, calls today, CSAT, etc.).  
   2. KPI tracker: charts (apexcharts) querying `/api/metrics`.  
   3. Integrations page: OAuth or API-key “Connect” buttons for  
      - HubSpot, Salesforce, Zoho, Pipedrive, Twilio Flex, Five9, RingCentral, Aircall, Zendesk, Freshdesk, Intercom, Help Scout.  
      Store tokens encrypted (crypto.aes-256).  
   4. Billing: usage, invoices (Stripe Portal link), update card.  
   5. Settings → Org owner can:  
      – Invite/disable team members, assign roles (`ORG_USER`, `VIEW_ONLY`).  
      – Toggle features allowed for each user.  
      – Regenerate API keys (write once, copy → clipboard).  
      – 2FA settings.

E. **Access-Code Registration Flow**
   Route `/register-with-code`  
   1. Form → Name, Email, Password, Access Code.  
   2. Validate: code unused, not expired (24 h).  
   3. Creates Org + ORG_OWNER user, marks code used-by + ts.

F. **Navigation / Routing**
   • Sticky NavBar & Footer visible on *all* pages.  
   • VictorySync colour palette only (#5E3BEE purple primary, #FFD400 accent).  
   • Active link underline + weight 600.  
   • Smooth page-to-top on every `<Link>` navigation.  
   • Mobile hamburger ≤ 1024 px (Headless UI).  
   • Footer: SxP links, social, © current-year, always full-width.

G. **Transitions & UX polish**
   • Framer-motion slide/opacity on route change.  
   • IntersectionObserver fade-in sections.  
   • Transition classes already in tailwind.config.  
   • Skeleton loaders for async panels.  
   • Toasts (sonner) for success/errors.

H. **Code Quality & Tooling**
   • ESLint + Prettier pass.  
   • Vitest unit + React-Testing-Library:  
     - NavBar  - RBAC hook  - Access-Code flow  - metrics reducer.  
   • E2E (Playwright) happy path: register → login → dashboard → logout.  
   • Typesafety end-to-end (tRPC or Zod validation).  
   • CI script `npm run ci` (lint, test).

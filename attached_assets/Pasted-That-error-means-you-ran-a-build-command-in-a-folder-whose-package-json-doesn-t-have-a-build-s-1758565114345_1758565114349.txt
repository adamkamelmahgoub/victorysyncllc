That error means you ran a build command in a folder whose **package.json doesn’t have a `"build"` script**. Your server is already looking for `client/dist/index.html`, so you just need to add a client build script and run it.

Here’s the quickest, exact fix.

---

## 1) Make sure the client has a build script

Open **`client/package.json`** and add the scripts block below (keep any others you already have). This assumes Vite (you’ve had Vite banners in your logs); if yours already has `"build"`, keep it—just make sure it runs `vite build`.

```json
{
  "name": "victorysync-web",
  "private": true,
  "version": "0.0.0",
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "preview": "vite preview --port 5173"
  },
  "devDependencies": {
    "typescript": "^5.0.0",
    "vite": "^5.0.0"
  }
}
```

> If you don’t use TypeScript in the client, you can simplify to `"build": "vite build"` and remove the `typescript` devDependency.

### If you hit the TS5069 error again

Edit **`client/tsconfig.node.json`** and either remove `tsBuildInfoFile` or set `"composite": true`. For example:

```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "composite": true,
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "types": ["node"]
  },
  "include": ["vite.config.ts"]
}
```

---

## 2) Install and build the client

Run these from the project root:

```bash
npm --prefix client install
npm --prefix client run build
```

This creates **`client/dist/index.html`**.

---

## 3) (Optional) Add a root shortcut so `npm run build` works

Open **`package.json`** at the repo root and add:

```json
{
  "scripts": {
    "build": "npm --prefix client run build",
    "web:dev": "npm --prefix client run dev",
    "api:dev": "tsx server/index.ts"
  }
}
```

Now `npm run build` at the root will build the front-end for you.

---

## 4) Restart your server

Stop and start your Replit run. You should now see a log like:

```
[web] Serving built SPA from /home/runner/workspace/client/dist/index.html
VictorySync API running on :5000
```

The root URL will render your **original front end** (the same UI you deploy), because the server will serve `client/dist/index.html`.

---

### Still not building?

* Run `cat client/package.json` and confirm there’s a `"build"` in `"scripts"`.
* Make sure you’re using the `--prefix client` commands from the repo root.
* If you are not using Vite (rare given your logs), change the build to the tool you actually use:

  * CRA: `"build": "react-scripts build"`
  * Next.js: `"build": "next build"` (and don’t serve with Express the same way)
* If you want the site to show immediately while you sort the build, set a proxy fallback (no build needed):

  * Add a secret `FRONTEND_URL=https://victorysync.com`
  * In `server/index.ts`, proxy non-`/api` routes to `FRONTEND_URL` (I can paste that block again if you want it here).

Do the steps above and your normal website will display from the server root.

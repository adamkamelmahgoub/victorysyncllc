#### Fix-list

1. **Create the missing Next.js pages/routes**

   * Add `src/app/login/page.tsx` (or equivalent) that renders our sign-in component.
   * If SSR is disabled, ensure a catch-all `[...auth].ts` isn’t blocking the route.
   * Add API file `src/pages/api/login.ts` (or Express proxy) that POSTs to `/api/auth/login`.

2. **Wire Passport strategies correctly**

   * In `server/auth/passport.ts` (or similar) **import and `passport.use()` each provider** under the canonical names `"google"`, `"facebook"`, `"apple"`:

     ```ts
     import GoogleStrategy from 'passport-google-oauth20';
     import FacebookStrategy from 'passport-facebook';
     import AppleStrategy from 'passport-apple';

     passport.use('google',  new GoogleStrategy(/* cfg */));
     passport.use('facebook', new FacebookStrategy(/* cfg */));
     passport.use('apple',   new AppleStrategy(/* cfg */));
     ```
   * Make sure this file is imported **before** route definitions so the strategies exist at bootstrap.

3. **Ensure callback routes hit `passport.authenticate('<provider>')` with the same name**

   * Example:

     ```ts
     router.get('/google',
       passport.authenticate('google', { scope: ['email', 'profile'] })
     );

     router.get('/google/callback',
       passport.authenticate('google', { session: false, failureRedirect: '/login' }),
       issueJwtAndRedirect
     );
     ```
   * Repeat for Facebook & Apple; names must match the `passport.use` tag to prevent the “Unknown authentication strategy” error.

4. **Build script issues**

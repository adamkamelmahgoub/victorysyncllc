# Explanation

You’ll get a **clean, accessible, conversion-focused MVP** for VictorySync—ready to paste into Replit and run. It includes:

* React + Vite + TailwindCSS, mobile-first, A11y-safe (skip links, focus rings, semantic landmarks)
* Pixel-clean Header/Footer with active states, sticky on scroll, and mobile drawer
* Pages mapped to a Verint-style structure but **fully tailored to VictorySync**: Home, Solutions, Platform, Industries, Pricing, ROI Center, Resources, About, Contact
* **ROI calculator** (client-side), **Calendly embed**, **Crisp live chat** hook, analytics hook, SEO/OG tags, JSON-LD
* Centralized content config, path aliases (`@/*`), scroll-to-top on route change
* All CTAs (“Get a Demo”, “See Pricing”, “Call Us”) routed and working

Copy points align with your plan (Cairo ops + AI, US clients, cost reduction “up to 60%”) and current CX priorities (voice for high-stakes, AI for self-service + agent assist). &#x20;

// client/src/ui/Header.tsx
import { NavLink } from "react-router-dom";
import { useEffect, useState } from "react";
import { site } from "@/content/site";

export default function Header() {
  const [open, setOpen] = useState(false);
  const [scrolled, setScrolled] = useState(false);
  useEffect(() => {
    const onScroll = () => setScrolled(window.scrollY > 8);
    window.addEventListener("scroll", onScroll);
    return () => window.removeEventListener("scroll", onScroll);
  }, []);
  const nav = [
    { to: "/", label: "Home", end: true },
    { to: "/solutions", label: "Solutions" },
    { to: "/platform", label: "Platform" },
    { to: "/industries", label: "Industries" },
    { to: "/pricing", label: "Pricing" },
    { to: "/resources", label: "Resources" },
    { to: "/about", label: "About" }
  ];
  const linkClass = ({ isActive }: { isActive: boolean }) =>
    "px-3 py-2 rounded-md transition " +
    (isActive ? "text-primary font-semibold" : "text-slate-700 hover:text-primary");

  return (
    <header className={(scrolled ? "shadow-vs " : "") + "sticky top-0 z-40 bg-white/90 backdrop-blur"}>
      <div className="mx-auto max-w-7xl px-4 sm:px-6 lg:px-8 h-16 flex items-center justify-between">
        <a href="/" className="flex items-center gap-2">
          <img src="/vs_400.png" alt="VictorySync logo" className="h-7 w-auto" />
          <span className="sr-only">{site.brand.name}</span>
        </a>
        <nav className="hidden md:flex items-center gap-1" aria-label="Main">
          {nav.map(n => (
            <NavLink key={n.to} to={n.to} end={n.end as boolean} className={linkClass}>
              {n.label}
            </NavLink>
          ))}
        </nav>
        <div className="hidden md:flex items-center gap-3">
          <a href="/contact" className="rounded-lg bg-primary px-4 py-2 text-white hover:bg-primary-600 transition">
            Get a Demo
          </a>
        </div>
        <button aria-label="Open Menu" className="md:hidden p-2" onClick={() => setOpen(v => !v)}>
          <span className="block h-0.5 w-6 bg-slate-900 mb-1"></span>
          <span className="block h-0.5 w-6 bg-slate-900 mb-1"></span>
          <span className="block h-0.5 w-6 bg-slate-900"></span>
        </button>
      </div>
      {open && (
        <div className="md:hidden border-t">
          <nav className="px-4 py-3 grid gap-1" aria-label="Mobile">
            {nav.map(n => (
              <NavLink key={n.to} to={n.to} onClick={() => setOpen(false)} className={linkClass}>
                {n.label}

            <a href="/contact" className="mt-2 rounded-lg bg-primary px-4 py-2 text-white text-center">Get a Demo</a>

// client/src/components/RoiCalculator.tsx
import { useMemo, useState } from "react";

export default function RoiCalculator() {
  const [volume, setVolume] = useState(3000);     // monthly contacts
  const [aht, setAht] = useState(5);              // minutes per contact
  const [usWage, setUsWage] = useState(18.25);    // $/hr baseline
  const [vsRate, setVsRate] = useState(7.5);      // $/hr effective (team+automation)

  const result = useMemo(() => {
    const hours = (volume * aht) / 60;
    const usCost = hours * usWage;
    const vsCost = hours * vsRate;
    const savings = Math.max(0, usCost - vsCost);
    const pct = usCost ? Math.round((savings / usCost) * 100) : 0;
    return { hours, usCost, vsCost, savings, pct };
  }, [volume, aht, usWage, vsRate]);

  const fmt = (n: number) => n.toLocaleString(undefined, { maximumFractionDigits: 0 });

  return (
    <div className="rounded-2xl border p-6">
      <h3 className="font-semibold text-lg">Estimate Your Savings</h3>
      <div className="mt-4 grid sm:grid-cols-2 gap-4">
        <label className="text-sm">Monthly Interactions
          <input className="mt-1 w-full rounded border px-3 py-2" type="number" value={volume} onChange={e=>setVolume(+e.target.value)}/>
        </label>
        <label className="text-sm">Avg Handle Time (min)
          <input className="mt-1 w-full rounded border px-3 py-2" type="number" step="0.1" value={aht} onChange={e=>setAht(+e.target.value)}/>
        </label>
        <label className="text-sm">U.S. Wage ($/hr)
          <input className="mt-1 w-full rounded border px-3 py-2" type="number" step="0.01" value={usWage} onChange={e=>setUsWage(+e.target.value)}/>
        </label>
        <label className="text-sm">VictorySync Effective ($/hr)
          <input className="mt-1 w-full rounded border px-3 py-2" type="number" step="0.01" value={vsRate} onChange={e=>setVsRate(+e.target.value)}/>
        </label>
      </div>
      <div className="mt-4 rounded-lg bg-slate-50 p-4 grid sm:grid-cols-2 gap-3 text-sm">
        <div>Total Hours: <strong>{fmt(result.hours)}</strong></div>
        <div>U.S. Cost: <strong>${fmt(result.usCost)}</strong></div>
        <div>VictorySync Cost: <strong>${fmt(result.vsCost)}</strong></div>
        <div>Savings: <strong className="text-green-700">${fmt(result.savings)} ({result.pct}%)</strong></div>
      </div>
      <a href="/contact" className="mt-4 inline-block rounded-lg bg-primary px-4 py-2 text-white hover:bg-primary-600 transition">
        Book an ROI Review
      </a>
    </div>
  );
}

* Put your images in the project root **/public**:

  * `/public/vs_favicon_32.png`, `/public/vs_favicon_64.png`, `/public/vs_400.png`, `/public/vs_800.png` (you have these assets).
* Run:

  ```bash
  npm i
  npm run dev
  ```

  Replit will serve on port **3000**.

2. **Wire the live parts**

* **Crisp Chat:** in `index.html`, replace `CRISP_WEBSITE_ID` with your Crisp site ID.
* **Calendly:** in `Contact.tsx`, replace `https://calendly.com/CALENDLY_URL` with your booking URL.
* **Analytics:** add your Plausible/GA script in `index.html` if desired.

3. **Branding & copy**

* If your exact brand blue differs, set it in `tailwind.config.cjs` → `colors.primary`.
* Centralized copy: `client/src/content/site.ts`. Update outcomes/integrations/CTAs here.

4. **Resources (optional)**

* Upload PDFs to `/public/resources/` to activate the Resource links.

5. **Build for production**

```bash
npm run build
npm run preview
```

* Deploy the `dist/` output using Replit’s deploy or a static host.

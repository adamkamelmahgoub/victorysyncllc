### Prompt for Replit AI Agent

**Problem:**
After logging in, the user is immediately logged out. The JWT token is either not stored, not sent, or not validated correctly.

---

### Fix this end-to-end:

#### ✅ 1. **Store the JWT on login**

In the login response handler (React or plain JS):

* After receiving `{ token }` from `/api/auth/login`, save it to `localStorage`:

  ```ts
  localStorage.setItem("token", token);
  ```
* Also redirect or show the dashboard after saving the token.

#### ✅ 2. **Send token in all protected API requests**

* Wherever the frontend calls `/api/auth/me`, `/dashboard`, etc., include:

  ```ts
  fetch('/api/auth/me', {
    headers: {
      Authorization: `Bearer ${localStorage.getItem("token")}`
    }
  });
  ```

#### ✅ 3. **Fix token verification middleware**

* In `authenticateJWT.ts` (or wherever it lives), verify the token like this:

  ```ts
  import jwt from "jsonwebtoken";

  export function authenticateJWT(req, res, next) {
    const authHeader = req.headers.authorization;
    if (!authHeader?.startsWith("Bearer ")) {
      return res.status(401).json({ error: "Missing token" });
    }

    const token = authHeader.split(" ")[1];

    try {
      const decoded = jwt.verify(token, process.env.JWT_SECRET);
      req.user = decoded;
      next();
    } catch (err) {
      return res.status(401).json({ error: "Invalid or expired token" });
    }
  }
  ```

#### ✅ 4. **Ensure the JWT is signed consistently**

* In the login route, issue tokens with:

  ```ts
  const token = jwt.sign({ id: user._id, email: user.email }, process.env.JWT_SECRET, { expiresIn: "30d" });
  ```

* Make sure `JWT_SECRET` is the same in `.env` and Replit Deployments → Environment.

#### ✅ 5. **Optional logout**

* Add a logout function that removes the token:

  ```ts
  localStorage.removeItem("token");
  ```

#### ✅ 6. **Test case**

* User logs in → token saved → navigates to dashboard
* Refresh page → token still valid → can fetch `/api/auth/me`
* Only logs out if token is missing, expired, or invalid.

---

**Goal:**
Fix all logout issues so users stay logged in across page reloads using localStorage + JWT with proper middleware.

Begin now. This should be fully working in both development and production builds.

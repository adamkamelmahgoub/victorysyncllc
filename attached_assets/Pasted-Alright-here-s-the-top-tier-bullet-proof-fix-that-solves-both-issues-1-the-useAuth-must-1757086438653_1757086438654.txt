Alright — here’s the **top-tier, bullet-proof fix** that solves both issues:

1. the `useAuth must be used within AuthProvider` crash, and
2. the “Skip to content” link showing all the time,
   …while also giving you a clean hero + subtle transitions.

Instead of relying on whichever entry file happens to run, we’ll **guarantee** every page (including `Navigation`) is wrapped by the same providers by moving them into the **layout** (`App.tsx`). That way, no matter which entry bootstraps React, the layout always provides `Auth`, `React Query`, and `Cart` contexts.

---

# Explanation

* The error happens because `Navigation` calls `useAuth()` but is rendered **outside** the `<AuthProvider>` (due to multiple entries or provider wrapping only in `main.tsx`).
* Moving providers into the top layout component (`App.tsx`) puts `Navigation`, `Outlet`, and everything else **inside** the providers, eliminating the error in all boot paths.
* We’ll add a tiny `RootProviders` wrapper to keep things clean.
* The skip-link will use Tailwind’s `sr-only` pattern so it’s visible only on keyboard focus.
* We’ll ensure a modern hero with smooth, accessible transitions.

---

# Code

### 1) Add a single place for providers

**`client/src/providers/RootProviders.tsx`** (new)

```tsx
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { AuthProvider } from "../contexts/AuthContext";
import { CartProvider } from "../contexts/CartContext";
import { ReactNode, useMemo } from "react";

export default function RootProviders({ children }: { children: ReactNode }) {
  // new client per app boot; memo to avoid re-creation on re-renders
  const qc = useMemo(() => new QueryClient(), []);
  return (
    <QueryClientProvider client={qc}>
      <AuthProvider>
        <CartProvider>{children}</CartProvider>
      </AuthProvider>
    </QueryClientProvider>
  );
}
```

### 2) Wrap the **layout** so Navigation is always inside providers

**Replace** the content of **`client/src/routes/App.tsx`**:

```tsx
import { Outlet } from "react-router-dom";
import Navigation from "../components/ui/navigation";
import Footer from "../components/ui/footer";
import RootProviders from "../providers/RootProviders";

export default function App() {
  return (
    <RootProviders>
      {/* a11y: visually hidden until focused */}
      <a
        href="#main"
        className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-[1000]
                   bg-white text-slate-900 border border-slate-300 rounded-md px-3 py-2 shadow"
      >
        Skip to content
      </a>

      <div className="min-h-screen flex flex-col">
        <Navigation />
        <main id="main" className="flex-1">
          <Outlet />
        </main>
        <Footer />
      </div>
    </RootProviders>
  );
}
```

> Moving providers here makes it impossible to render `Navigation` without them.

### 3) Keep your entry lean (no providers here anymore)

**`client/src/main.tsx`** – keep just the router (if yours still has providers, remove them):

```tsx
import { StrictMode, Suspense } from "react";

import "./index.css";

import Home from "./pages/home";

import About from "./pages/about";
import Contact from "./pages/contact";
import Login from "./pages/login";

import ResourceDetail from "./pages/ResourceDetail"; // remove if you don't have it

// Simple guard component (should already exist)

const router = createBrowserRouter([
  {
    path: "/",
    element: <App />, // <-- Providers live inside App
    children: [
      { index: true, element: <Home /> },
      { path: "solutions", element: <Solutions /> },
      { path: "platform", element: <Platform /> },
      { path: "industries", element: <Industries /> },
      { path: "pricing", element: <Pricing /> },
      { path: "roi", element: <RoiCenter /> },
      { path: "resources", element: <Resources /> },
      { path: "resources/:slug", element: <ResourceDetail /> },
      { path: "about", element: <About /> },
      { path: "contact", element: <Contact /> },
      { path: "login", element: <Login /> },
      {
        path: "customer-dashboard",
        element: (
          <PrivateRoute>
            <CustomerDashboard />
          </PrivateRoute>
        ),
      },
      { path: "*", element: <div className="p-8 text-center">404 — Not found</div> },
    ],
  },
]);

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <Suspense fallback={<div className="p-6">Loading…</div>}>
      <RouterProvider router={router} />
    </Suspense>
  </StrictMode>
);
```

# Instructions

1. Create **`client/src/providers/RootProviders.tsx`** and paste the code.
2. Replace **`client/src/routes/App.tsx`** with the provider-wrapped layout above.
3. Ensure **`client/src/main.tsx`** is **router-only** (no providers).

   * If your root `index.html` points to `/src/main.tsx`, keep the small trampoline file there:

     ```ts
     // src/main.tsx
     import "../client/src/main.tsx";
     ```
4. (Optional) Add the Hero files if not present.
5. In the Replit Console:

   ```bash
   npm i @tanstack/react-query react-router-dom
   rm -rf node_modules/.vite
   npm run dev
   ```
6. Refresh Preview.

---

# Warnings

* **Do not** render providers in multiple places (we’ve centralized them in `App.tsx`).
* **Casing matters** on Linux (e.g., `Platform.tsx` vs `platform.tsx`).
* If you previously added `/src/contexts/*` shims, they’re fine to keep; they don’t conflict with this layout-centric approach.

This pattern locks your layout (and thus `Navigation`) **inside** the providers no matter the entry, eliminates the Auth crash, hides the skip link until focus, and gives you a clean, animated hero.

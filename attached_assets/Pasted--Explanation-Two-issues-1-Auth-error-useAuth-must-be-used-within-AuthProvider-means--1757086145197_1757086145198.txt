# Explanation

Two issues:

1. **Auth error**: `useAuth must be used within AuthProvider` means your running entry isn’t wrapping the app with `AuthProvider` (and likely `QueryClientProvider` + `CartProvider`). Fix by replacing `client/src/main.tsx` with a provider-wrapped root and making sure `src/main.tsx` only imports that file (no second root).
2. **“Skip to content” visible**: keep the a11y link, but hide it until keyboard focus. Do it right in markup with Tailwind’s `sr-only` utilities (works even if your CSS didn’t load).

Below are exact, surgical patches.

---

# Code

### 1) Wrap the whole app with providers (fixes the Auth error)

**Replace** `client/src/main.tsx` completely:

```tsx
// client/src/main.tsx
import { StrictMode, Suspense } from "react";
import { createRoot } from "react-dom/client";
import { createBrowserRouter, RouterProvider } from "react-router-dom";
import "./index.css";

// Pages/routes (use exact filenames/casing)
import App from "./routes/App";
import Home from "./pages/home";
import Solutions from "./pages/services";
import Platform from "./pages/Platform";
import Industries from "./pages/Industries";
import Pricing from "./pages/pricing";
import RoiCenter from "./pages/RoiCenter";
import Resources from "./pages/Resources";
import About from "./pages/about";
import Contact from "./pages/contact";
import Login from "./pages/login";
import CustomerDashboard from "./pages/customer-dashboard";
// If you created this file keep it; otherwise remove this import and its route:
import ResourceDetail from "./pages/ResourceDetail";

// Providers
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { AuthProvider } from "./contexts/AuthContext";
import { CartProvider } from "./contexts/CartContext";

// Guard
import PrivateRoute from "./ui/PrivateRoute";

const router = createBrowserRouter([
  {
    path: "/",
    element: <App />,
    children: [
      { index: true, element: <Home /> },
      { path: "solutions", element: <Solutions /> },
      { path: "platform", element: <Platform /> },
      { path: "industries", element: <Industries /> },
      { path: "pricing", element: <Pricing /> },
      { path: "roi", element: <RoiCenter /> },
      { path: "resources", element: <Resources /> },
      { path: "resources/:slug", element: <ResourceDetail /> },
      { path: "about", element: <About /> },
      { path: "contact", element: <Contact /> },
      { path: "login", element: <Login /> },
      {
        path: "customer-dashboard",
        element: (
          <PrivateRoute>
            <CustomerDashboard />
          </PrivateRoute>
        ),
      },
      { path: "*", element: <div className="p-8 text-center">404 — Not found</div> },
    ],
  },
]);

const qc = new QueryClient();

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <QueryClientProvider client={qc}>
      <AuthProvider>
        <CartProvider>
          <Suspense fallback={<div className="p-6">Loading…</div>}>
            <RouterProvider router={router} />
          </Suspense>
        </CartProvider>
      </AuthProvider>
    </QueryClientProvider>
  </StrictMode>
);
```

If your root `index.html` points to `/src/main.tsx`, make sure **`src/main.tsx`** is **only** this one-liner (no second render):

```ts
// src/main.tsx  (trampoline only)
import "../client/src/main.tsx";
```

> This guarantees there’s exactly one `AuthContext` and that all components (e.g., `Navigation`) render under its `<AuthProvider>`.

### 2) Make the skip link visible only on keyboard focus (no global CSS required)

Put the skip link **before your header/nav** in `client/src/routes/App.tsx` and use Tailwind’s utilities:

```tsx
// client/src/routes/App.tsx
import { Outlet } from "react-router-dom";
import Navigation from "../components/ui/navigation";
import Footer from "../components/ui/footer";

export default function App() {
  return (
    <div className="min-h-screen flex flex-col">
      {/* Hidden until focused by keyboard */}
      <a
        href="#main"
        className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-[1000] 
                   bg-white text-slate-900 border border-slate-300 rounded-md px-3 py-2 shadow"
      >
        Skip to content
      </a>

      <Navigation />
      <main id="main" className="flex-1">
        <Outlet />
      </main>
      <Footer />
    </div>
  );
}
```

> Using `sr-only` + `focus:not-sr-only` means it’s hidden visually but appears when tabbed to (best practice).
